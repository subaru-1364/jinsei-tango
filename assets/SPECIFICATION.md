# 人生新出単語 仕様書・API管理規約

本ドキュメントは「人生新出単語」のシステム構成、機能要件、データ仕様、および外部API・セキュリティ管理方針を定義した仕様書です。

---

## 1. アプリケーション概要

- **名称**: 人生新出単語
- **用途**: 日常や読書の中で新しく出会った単語を記録し、書籍（ISBN）ごとの整理・辞書からの意味自動補完・重複なしランダムピックアップを行うWebアプリケーション。
- **特徴**:
  - Googleログイン必須によるPC・スマホ間のリアルタイムクラウド同期（Firebase Authentication / Realtime Database）
  - ISBN（13桁/10桁）またはタイトル検索からの書名・著者・表紙（書影）自動取得と書籍別シート管理
  - 国語辞典データ（Wiktionary / Wikipedia）からの意味自動付与と候補切り替え・確定機能
  - 全単語が一巡するまで同じ単語が重複しない「山札シャッフル方式」のランダムピックアップ

## 3. 外部API・APIキー管理・課金防止方針

本アプリは GitHub Pages（静的サイト）で公開されるため、**「課金が発生するAPIキーを一切持たない・埋め込まない」** 設計としています。

| 用途 | 使用API | APIキー | 課金・請求リスク | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| **書名・著者・書影（ISBN／タイトル検索）** | **Google Books API** (`volumes?q=isbn:...`) | **不要（未使用）** | **ゼロ（有料プラン自体が存在しない）** | 無料枠（1日1,000回/IP）超過時もエラーが返るだけで請求は一切発生しない |
| **書名・著者・書影** | **openBD API** (`api.openbd.jp`) | **不要** | **ゼロ（完全無料公開）** | 日本の出版業界による公開書誌・書影データ |
| **単語の意味取得** | **Wiktionary / Wikipedia API** | **不要** | **ゼロ（完全無料公開）** | ウィキメディア財団による無料公開API |
| **ログイン・同期** | **Firebase Auth / Realtime DB** | 公開識別子 (`firebaseConfig`) | **ゼロ（Spark無料プラン）** | クレジットカード未登録のSparkプランのため自動課金なし。DBルールで本人UIDのみ読み書き可能 |

## 4. 主要機能仕様

1. **ログイン必須ゲート（ローカル確認モード対応）**
   - 未ログイン状態ではログイン案内画面（`#login-gate`）を表示し、未ログイン時のローカル保存によるデータ不整合を防止（`localhost` / `file://` 環境では即時確認用のローカルプレビューモードも選択可能）。
2. **書籍（ISBN・タイトル検索）別シート管理**
   - ISBNまたは本のタイトル検索（Wikipedia＋openBD / Google Books）で本棚タブを作成し、`edit.html` では選択中の本（または「未分類」）のシート単位で分割管理。外部APIに書影が存在しない書籍や任意作成シートには、書名先頭6文字を配したミニ本風プレースホルダー（`.book-cover-placeholder`）を表示。
   - 「並び替え」モード時、下部の「← 左へ移動」「右へ移動 →」ボタンやドラッグ＆ドロップによりシートの表示順を任意に入れ替え可能（「すべて」「未分類」は常に先頭に固定）。
   - 各単語カードのインライン編集から「単語そのものの修正」「意味の修正」「別の本（シート）への移動」が可能。また、カードやピックアップ結果の下部にシート名（`.word-source`）を控えめに表示（「未分類」時は非表示）。
   - 単語一覧・シート編集ともに100件単位のページネーションを採用し、大量登録時もDOM負荷を一定に維持。
   - 内部データ形式は `# [BOOK:id|isbn|title|author|cover]` セクションヘッダーにより `bulkText` としてシリアライズされ、Firebase Realtime Database 上では100行ごとのチャンク（`c0000`, `c0001`...）に分割して差分同期。
3. **意味の自動付与と確認モーダル**
   - 「意味の自動取得時に確認する」設定がONのときは確認モーダル（`#meaning-confirm-modal`）を表示し、候補選択・手動編集・「この意味で確定」「✓ 意味不要(分かる)」「キャンセル／スキップ」を選択可能。
   - 確認設定がOFFのときは `[自動]` バッジ付きで自動登録され、後からカード上で「✓ この意味で確定」「別の候補」「意味だけ消す」を選択可能。
4. **重複なしランダムピックアップ（山札方式）**
   - Fisher-Yatesシャッフルにより山札（`drawDeck`）を生成し、全単語が一巡するまで同じ単語が重複して出ない仕組み。
5. **重複（かぶり）の自動防止とゾンビ復活の防止**
   - 単語の新規追加時に、未分類や他の書籍シートに同一単語が既に存在する場合は自動的にスキップし、メッセージで登録済みであることを通知。
   - 単語カードの削除時は、他シートに同一単語が残って復活（ゾンビ化）することを防ぐため、全シートから該当単語を一括削除。

## 5. 利用規約・法令遵守メモ（公開サイトとして運用するための方針）

| 項目 | 方針 |
| :--- | :--- |
| **Apple Books / iTunes Search API** | 規約上、書影等は「ストア商品の宣伝（公式バッジ＋商品リンク）」にしか使えないため**使用しない**。過去に保存された `mzstatic.com` / `apple.com` 由来の表紙URLは読み込み時に破棄する |
| **NDL書影API（ndlsearch.ndl.go.jp/thumbnail）** | 2026年3月31日でサービス終了のため**使用しない** |
| **Wikipedia / Wiktionary** | 文章は CC BY-SA 4.0。画面下部に出典・ライセンスへのリンクを常時表示。取得した意味は誤りを含み得ることを明記 |
| **openBD** | 書影・書誌は「本の紹介」目的のみ。データを改変しない／削除要請には速やかに従う。表紙は**URL文字列のみ保存**し画像ファイルは複製・再配布しない |
| **Google Books API（キーなし）** | 画面下部に提供元を表示。表紙は**URL文字列のみ保存**。商用・有料化する場合は別途Googleの許可が必要 |
| **広告・課金** | 広告掲載・有料化は行わない（行う場合は各APIの規約・NDLメタデータ条件を再確認すること） |
| **個人情報** | Googleログイン（Firebase Auth）で取得するのはログイン識別子（UID）のみ。DBルールで本人以外の読み書きを遮断する |
