# 人生新出単語 仕様書・API管理規約

本ドキュメントは「人生新出単語」のシステム構成、データスキーマ、機能要件、および外部API・セキュリティ管理方針を定義した仕様書です。

---

## 1. アプリケーション概要

- **名称**: 人生新出単語
- **用途**: 日常や読書の中で新しく出会った単語を記録し、書籍（ISBN）ごとの整理・辞書からの意味自動補完・重複なしランダムピックアップを行うシングルページWebアプリケーション（SPA）。
- **特徴**:
  - Googleログイン必須によるPC・スマホ間のリアルタイムクラウド同期（Firebase Authentication / Realtime Database）
  - ISBN（13桁/10桁）またはタイトル検索からの書名・著者・表紙（書影）自動取得と書籍別シート管理
  - 表紙（書影）のカスタマイズ機能（伝統色12色パレット、カラーピッカー、画像URL指定、自動再取得）
  - 国語辞典データ（Wiktionary / Wikipedia）からの意味自動付与と候補切り替え・確定機能
  - 全単語が一巡するまで同じ単語が重複しない「山札シャッフル方式」のランダムピックアップ

## 3. データスキーマ（v2 JSON形式）と同期仕様

### 3.1 データ構造（v2）
本棚（`books`）と単語（`words`）を構造化JSONとして管理します。

- **LocalStorage (`kuji_data_v2`)**:
  ```json
  {
    "version": 2,
    "updatedAt": 1700000000000,
    "books": [
      {
        "id": "book_9784000000000",
        "isbn": "9784000000000",
        "title": "吾輩は猫である",
        "author": "夏目漱石",
        "cover": "#1e3a5f",
        "order": 0,
        "createdAt": 1700000000000
      }
    ],
    "words": [
      {
        "id": "w_...",
        "word": "吾輩",
        "meaning": "我が輩。自分を尊大に呼ぶ語",
        "bookId": "book_9784000000000",
        "isAutoMeaning": false,
        "noMeaningNeeded": false,
        "order": 10,
        "createdAt": 1700000000000
      }
    ]
  }
  ```

- **Firebase Realtime Database (`users/{uid}`)**:
  `books/{bookId}` および `words/{wordId}` のキー付きマップとして格納し、追加・変更・削除があったエンティティのみをピンポイントで差分送信（`update`）することで通信量・データ容量を最小化しています。

### 3.2 旧形式（v1テキスト・チャンク）からの自動移行
- 初回起動時およびクラウド同期時に、旧形式（`kuji_chunk_*` / `kuji_bulk_text` / Firebase `chunks`）を検出した場合は自動的に v2 JSON構造へ変換・移行し、旧キーをクリーンアップします。

## 4. 外部API・APIキー管理・課金防止方針

本アプリは GitHub Pages（静的サイト）で公開されるため、**「課金が発生するAPIキーを一切持たない・埋め込まない」** 設計としています。

| 用途 | 使用API | APIキー | 課金・請求リスク | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| **書名・著者・書影（ISBN／タイトル検索）** | **Google Books API** (`volumes?q=...`) | **不要（未使用）** | **ゼロ（有料プランなし）** | 無料枠超過時もエラー返却のみで請求は一切発生しない |
| **書名・著者・書影** | **openBD API** (`api.openbd.jp`) | **不要** | **ゼロ（完全無料公開）** | 日本の出版業界による公開書誌・書影データ |
| **単語の意味取得** | **Wiktionary / Wikipedia API** | **不要** | **ゼロ（完全無料公開）** | ウィキメディア財団による無料公開API |
| **ログイン・同期** | **Firebase Auth / Realtime DB** | 公開識別子 (`firebaseConfig`) | **ゼロ（Spark無料プラン）** | Sparkプランのため自動課金なし。DBルールで本人UIDのみ読み書き可能 |

## 5. 主要機能仕様

1. **ログイン必須ゲート（ローカル確認モード対応）**
   - 未ログイン状態ではログイン案内画面（`#login-gate`）を表示し、未ログイン時の不整合を防止（`localhost` / `file://` 環境では即時プレビュー可能）。
2. **本棚・書籍別シート管理と書影設定**
   - ISBNまたは書籍タイトル検索で本棚タブを作成。並び替えモードによりドラッグ＆ドロップやボタンで順序変更が可能。
   - 書影設定モーダル（`#book-cover-modal`）から、12色の単色カラーパレット、自由色ピッカー、画像URL、API自動取得を選択可能。未設定時は書籍名から決定論的に落ち着いた単色背表紙を自動割り当て。
3. **単語追加モーダルと辞書自動付与**
   - ヘッダーの「単語を追加」からモーダル（`#word-add-modal`）を開き、読書中でも画面遷移なしで複数単語を一括登録可能（`Ctrl+Enter` / `Cmd+Enter` 対応）。
   - 「意味を確認する」ON時は確認モーダル（`#meaning-confirm-modal`）を表示し、OFF時は `[自動]` バッジ付きで登録。一覧ヘッダーの「辞書補完」ボタンで未登録単語の一括補完も可能。
4. **重複なしランダムピックアップ（山札方式）**
   - Fisher-Yatesシャッフルにより山札（`drawDeck`）を生成し、全単語が一巡するまで同じ単語が重複して出ない仕組み。
5. **重複防止・XSS防止**
   - アプリ全体で同一単語の重複登録を自動スキップ。
   - ユーザー入力値・外部API値の描画には `innerHTML` を一切使用せず、`textContent` と `document.createElement` のみを使用。

## 6. 利用規約・法令遵守メモ

| 項目 | 方針 |
| :--- | :--- |
| **Apple Books / iTunes Search API** | 規約上の制約により**使用しない**。`mzstatic.com` / `apple.com` 由来のURLは破棄する |
| **NDL書影API** | 2026年3月31日でサービス終了のため**使用しない** |
| **Wikipedia / Wiktionary** | CC BY-SA 4.0 に基づきフッターに出典・ライセンスを常時表示 |
| **openBD / Google Books** | フッターに提供元を表示。表紙は**URL文字列（またはカラーコード）のみ保存**し画像ファイルは複製・再配布しない |
| **個人情報** | Firebase Auth で取得するのは識別子（UID）のみ。DBルール（`auth != null && auth.uid === $uid`）で本人以外の読み書きを遮断 |
